# Little Vet: Animal Doctor - Privacy Policy

This repository hosts the official Privacy Policy for the Android game **Little Vet: Animal doctor** (`com.mouse.littlevet`) by **Green Mouse**.

### Web URL
Once GitHub Pages is enabled for this repository (`main` branch, root `/`), the privacy policy is available at:
[https://dziher11.github.io/LittleVet/](https://dziher11.github.io/LittleVet/)

---

### Key Points
- **Zero data collection:** The app does not collect, transmit, or share any personal data.
- **Offline operation:** The app functions 100% offline with no network requests; game progress is stored only locally on the device.
- **Zero permissions:** No device permissions are requested or used.
- **Child-safe & COPPA compliant:** Fully compliant with Google Play Designed for Families, GDPR-K, and COPPA policies.
- **No ads:** 100% free of advertising, in-app purchases, and third-party trackers.
